# rule-engine

Движок правил для умного дома. На вход подаётся поток токенов (слов) с
уверенностью детектора, на выходе получаются сработавшие сценарии.

## Как работает

1. В [examples/smart_home.json](examples/smart_home.json) заданы словарь токенов
   (`vocabulary`) и сценарии (`scenarios`). У сценария есть имя и фраза из
   токенов через пробел.
2. Из сценариев строится префиксное дерево: у сценариев с общим началом общие
   вершины.
3. Каждый токен потока двигает частичные совпадения по рёбрам дерева. Когда
   совпадение доходит до вершины, где заканчивается сценарий, сценарий
   срабатывает.

Правила прохода:

- токен, для которого нет подходящего ребра, пропускается, и совпадение ждёт
  дальше;
- в одной вершине может стоять только одно совпадение; из двух остаётся то,
  что началось позже;
- если из вершины, где сработал сценарий, есть продолжение, совпадение идёт
  дальше;
- токен, которого нет в словаре, вызывает ошибку.

## Граф

```
  ┌─включи───>( )─свет─>( )─в─>( )─┬─ванной──>( ) «свет в ванной: включить»
  │                                └─спальне─>( ) «свет в спальне: включить»
  ├─выключи──>( )─свет─>( ) «свет: выключить»
  │                      └─закрой─>( )─дверь─>( ) «ухожу из дома»
●─┼─разогрей─>( )─┬─чайник─>( ) «чайник: разогреть»
  │               └─ванну──>( ) «ванна: разогреть»
  ├─открой───>( )─шторы─>( ) «шторы: открыть»
  │                       └─разогрей─>( )─чайник─>( ) «утро»
  └─закрой───>( )─дверь─>( ) «дверь: закрыть»
```

```
●        начало
( )      вершина
(*)      здесь стоит частичное совпадение
─x─>     ребро с токеном x
═x═>     ребро, по которому совпадение уже прошло
«…»      здесь заканчивается сценарий
✓ «…»    сценарий сработал
```

## Примеры

`#N` — номер события в потоке.

**«разогрей ванну»: выбор ветки в общей вершине**

```
#0 разогрей  ●═разогрей═>(*)─┬─чайник─>( )
                             └─ванну──>( )
#1 ванну     ●═разогрей═>( )─┬─чайник─>( )
                             └═ванну══>( )  ✓ «ванна: разогреть»
```

**«включи пожалуйста свет в ванной»: посторонний токен пропускается**

```
#0 включи      ●═включи═>(*)─свет─>( )─в─>( )─ванной─>( )
#1 пожалуйста  ●═включи═>(*)─свет─>( )─в─>( )─ванной─>( )   ребра «пожалуйста» нет: ждём
#2 свет        ●═включи═>( )═свет═>(*)─в─>( )─ванной─>( )
#3 в           ●═включи═>( )═свет═>( )═в═>(*)─ванной─>( )
#4 ванной      ●═включи═>( )═свет═>( )═в═>( )═ванной═>( )   ✓ «свет в ванной: включить»
```

**«открой шторы и разогрей чайник»: два совпадения сразу, короткий сценарий внутри длинного**

```
#0 открой    ●═открой═>(*)─шторы─>( )─разогрей─>( )─чайник─>( )
#1 шторы     ●═открой═>( )═шторы═>(*)─разогрей─>( )─чайник─>( )   ✓ «шторы: открыть»
#2 и         ●═открой═>( )═шторы═>(*)─разогрей─>( )─чайник─>( )   ребра «и» нет: ждём
#3 разогрей  ●═открой═>( )═шторы═>( )═разогрей═>(*)─чайник─>( )
             ●═разогрей═>(*)─чайник─>( )                          + новое из начала
#4 чайник    ●═открой═>( )═шторы═>( )═разогрей═>( )═чайник═>( )   ✓ «утро»
             ●═разогрей═>( )═чайник═>( )                          ✓ «чайник: разогреть»
```

**«разогрей разогрей чайник»: два совпадения в одной вершине склеиваются**

```
#0 разогрей  ●═разогрей═>(*)─чайник─>( )   совпадение с #0
#1 разогрей  ●═разогрей═>(*)─чайник─>( )   сюда же пришло новое с #1, место одно: остаётся #1
#2 чайник    ●═разогрей═>( )═чайник═>( )   ✓ «чайник: разогреть» из #1 #2, один раз
```

## Форматы

Правила лежат в [examples/smart_home.json](examples/smart_home.json):

```json
{
  "vocabulary": ["разогрей", "чайник", "ванну", "пожалуйста"],
  "scenarios": [{"name": "чайник: разогреть", "pattern": "разогрей чайник"}]
}
```

Поток лежит в [examples/stream.txt](examples/stream.txt): одна строка на событие,
в формате `токен уверенность`. Пустые строки и строки, начинающиеся с `#`,
пропускаются. Уверенность хранится в событии, но на срабатывание не влияет.

## Файлы

- [rules.py](src/rule_engine/rules.py): словарь и сценарии, загрузка JSON, проверки;
- [graph.py](src/rule_engine/graph.py): построение и печать графа;
- [engine.py](src/rule_engine/engine.py): проход потока по графу;
- [cli.py](src/rule_engine/cli.py): командная строка.

## Запуск

```bash
uv sync
uv run rule-engine graph examples/smart_home.json                    # показать граф
uv run rule-engine run examples/smart_home.json examples/stream.txt  # прогнать поток
uv run pytest
```
