# токен уверенность время(с)
# общая уверенность совпадения — среднее геометрическое score его шагов: (s1·…·sk)^(1/k).
# Сценарий срабатывает, только если она не ниже min_confidence: стандартный порог 0.6 из корня
# правил, у «ухожу из дома» свой — 0.8. В выводе run она стоит после имени сценария. Группы
# разнесены больше чем на 10 с, срабатывания «взлома» — больше чем на минуту (cooldown)

# две <дверь>: первая увереннее, вторая свежее и проживёт дольше. Ни одна не вытесняет другую, в
# наборе «взлома» {<дверь>} стоят обе. <громкий звук> продолжает обе, и выдаётся самое уверенное:
# √(0.90·0.80) = 0.85 по первой двери. По второй было бы √(0.40·0.80) = 0.57 < 0.6
<дверь> 0.90 0.0
<дверь> 0.40 8.0
<громкий звук> 0.80 9.0

# то же, но <громкий звук> через 11 с после первой двери: её срок 10 с истёк, а по второй
# 0.57 < 0.6, и «взлом» не срабатывает
<дверь> 0.90 100.0
<дверь> 0.40 108.0
<громкий звук> 0.80 111.0

# оба токена проходят порог «взлома» 0.3, но √(0.95·0.35) = 0.58 < 0.6, и «взлом» не срабатывает.
# Среднее арифметическое дало бы 0.65: уверенная дверь перекрыла бы слабый звук, хотя взлом
# отличает именно звук
<дверь> 0.95 200.0
<громкий звук> 0.35 201.0

# ранний отсев: <дверь> 0.31 проходит порог 0.3, но даже при <громкий звук> 1.00 вышло бы
# √0.31 = 0.56 < 0.6, поэтому совпадение снимается сразу. Звук «взлома» не даёт: он только
# начинает новый набор и ждёт дверь
<дверь> 0.31 220.0
<громкий звук> 1.00 221.0

# «выключи свет, закрой дверь» неуверенно: «свет: выключить» √(0.70·0.75) = 0.72 и «дверь:
# закрыть» √(0.70·0.80) = 0.75 проходят стандартный порог 0.6, а «ухожу из дома» со своим
# порогом 0.8 — нет. Продолжение «выключи свет закрой» отсеивается сразу: даже при «дверь» 1.00
# вышло бы (0.70·0.75·0.70)^(1/4) = 0.78 < 0.8
выключи 0.70 240.0
свет 0.75 240.4
закрой 0.70 241.9
дверь 0.80 242.3
