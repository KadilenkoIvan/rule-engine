# Радио-няня: правила examples/nanny.json.
# «тишина у ребёнка» — 900 с (15 минут) после последнего токена без единого токена, даже вне
# словаря: `any` и как шаг, и в absent. Каждый токен снимает окно прежнего и открывает своё.
# «ребёнок затих» — 300 с после плача без токенов словаря (`any_vac`): шум вне словаря не мешает.
# Назад тишины не смотрят: before по умолчанию 0.

# 1. Поплакал и затих.
<плач> 0.90 0
<голос> 0.80 20
<плач> 0.90 40
1000
# 340: ✓ ребёнок затих — 300 с после второго плача; первый плач снят голосом
# 940: ✓ тишина у ребёнка — 900 с после второго плача

# 2. Гул вне словаря: «тишину у ребёнка» нарушает, «ребёнок затих» — нет.
<плач> 0.90 2000
<гул> 0.90 2200
3500
# 2300: ✓ ребёнок затих — гул не из словаря
# 3100: ✓ тишина у ребёнка — от гула: 900 с после него

# 3. Шорохи: тихий не в счёт, громкий переносит отсчёт.
<шорох> 0.80 4000
<шорох> 0.30 4500
<шорох> 0.80 4600
5600
# 0.30 ниже порога 0.5: ни окна не снимает, ни своего не открывает
# 5500: ✓ тишина у ребёнка — 900 с после шороха в 4600
